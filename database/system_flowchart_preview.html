🔄 MacroPulse Terminal — System Flowchart

End-to-End Operational Lifecycle: Authentication → Workspace Routing → Real-Time Ingestion → AI Telemetry → Persistence

flowchart TD
    Start([🚀 User Accesses MacroPulse Terminal]) --> CheckAuth{"Active Session Token?
(Local Storage)"}

    %% Authentication
    CheckAuth -- "No / Expired" --> LoginModal["🔐 Display Authentication Portal
(Email/Password, Google OAuth 2.0 GIS, OTP Reset)"]
    LoginModal --> SubmitAuth["Submit Credentials to /api/auth/*"]
    SubmitAuth --> ValidateAuth{"Valid Credentials?"}
    
    ValidateAuth -- "No" --> LogFail["Log Failed Attempt in LOGIN_ATTEMPTS"]
    LogFail --> ShowAuthErr["Display Authentication Error Banner"]
    ShowAuthErr --> LoginModal
    
    ValidateAuth -- "Yes" --> GenSession["Generate Cryptographic Session Token
(mp_live_... in USER_SESSIONS)"]
    GenSession --> LoadProfile["Load User Profile & Regional Settings
(USER_WORKSPACE_SETTINGS)"]

    CheckAuth -- "Yes" --> ValidateToken{"Validate Token with Server?"}
    ValidateToken -- "Valid" --> LoadProfile
    ValidateToken -- "Invalid" --> LoginModal

    %% Workspace
    LoadProfile --> InitTerminal["🖥️ Initialize Institutional Workspace
• Apply Theme & Base Currency (MYR/USD/EUR/SGD)
• Configure Polling Frequency (15s Default)
• Initialize Web Audio API Synth Engine"]
    
    InitTerminal --> RouteNav{"Select Navigation View
(Sidebar Tabs)"}

    %% 6 Dashboards
    RouteNav -->|#view-overview| ViewOverview["📊 1. Macro & Equities Overview
• Ingest /api/market-pulse
• Render Canvas Micro-Sparklines
• Policy Rate vs. KLCI Wave Chart
• Sector Rotation Breakdown"]
    
    RouteNav -->|#view-logs| ViewPolicy["🏛️ 2. Central Bank Policy & Rates
• Query St. Louis Fed FRED Series
• Render Policy Corridor Gauge
• Streaming Real-Time Newswire Ticker"]
    
    RouteNav -->|#view-trading| ViewTrading["📈 3. Stock Analysis & Trading Terminal
• Fetch yfinance Quotes (/api/stock-history)
• Render HiDPI HTML5 Canvas Candlestick Chart
• Dynamic FX Base Currency Conversion
• Synthetic Order Book Depth Ladder"]
    
    RouteNav -->|#view-analytics| ViewAnalytics["🌐 4. Global FX & Sovereign Yields
• Ingest MGS, UST, Bund & JGB Curves
• Compute 10Y-2Y Inversion Spreads
• Foreign Capital Inflows Telemetry"]
    
    RouteNav -->|#view-models| ViewModels["🧠 5. AI Model Performance Console
• Benchmark 5 Architectures (BiLSTM, XGBoost...)
• Compute Error Metrics (RMSE, MAE, MAPE)
• Render 95% Gaussian Confidence Envelope
• Audit Run Logs & RFC 4180 CSV Export"]
    
    RouteNav -->|#view-settings| ViewSettings["⚙️ 6. Workspace Settings & Governance
• Profile & Bio Synchronization
• Password Complexity Validation Meter
• User Notification Alert Rules"]

    %% Telemetry & Background Loops
    ViewOverview --> PollingLoop["⏱️ Background Polling Worker
(Every 15 Seconds)"]
    ViewTrading --> PollingLoop
    ViewPolicy --> PollingLoop

    PollingLoop --> FetchAPI["Fetch Live Market Data & Ingest Macro Signals"]
    FetchAPI --> CheckAlerts{"Threshold Triggered?
(OPR Change / Watchlist Alert)"}
    
    CheckAlerts -- "Yes" --> WebAudio["🔔 Synthesize Audio Chime Alert
(Web Audio Oscillator + Toast Notification)"]
    CheckAlerts -- "No" --> RefreshUI["Update Active DOM Elements & Canvas Pixels"]
    WebAudio --> RefreshUI

    %% User Actions
    RefreshUI --> UserAction{"Analyst Action"}
    
    UserAction -->|Switch Tab| RouteNav
    UserAction -->|Manage Watchlist| DBWatchlist["Persist in USER_WATCHLISTS (MySQL)"] --> RefreshUI
    UserAction -->|Execute AI Model| ExecuteModel["Run Model Inference / Backtest Pipeline"] --> LogModel["Persist Metrics in MODEL_RUN_LOGS"] --> RefreshUI
    UserAction -->|Update Settings| SaveSettings["Save Preferences to USER_WORKSPACE_SETTINGS"] --> RefreshUI
    UserAction -->|Download Report| ExportReport["Generate Printable PDF / Market Report"] --> RefreshUI
    UserAction -->|Logout| TerminateSession["Invalidate Token in USER_SESSIONS
& Clear Local Storage"] --> LoginModal
